# R04 — نور، سایه و متریال

**وضعیت:** تکمیل‌شده در ۲۰۲۶-۱۰-۲۱. **وابستگی:** R03. **Skill:** `frontend-design`؛ پشتیبان: `performance-optimization`. **خروجی:** ظاهر نهایی و یکپارچهٔ صحنهٔ Hero.

## هدف و محدوده

به مدل‌های تأییدشده نور، سایه و متریال بده تا عمق و خوانایی داشته باشند و با Hero مینیمال همخوان بمانند. کیفیت پرداخت و عمق بصری از BFCM الهام می‌گیرد؛ رنگ‌بندی، اشیاء، آمار و هویت BFCM کپی نمی‌شوند.

## فایل‌های مورد بررسی و تغییر احتمالی

- `src/RoomScene.tsx` و مدل‌های محلی در `public/assets/models/`
- `tests/entry-page.spec.ts` و `tests/room-navigation.spec.ts` برای smoke مرور صحنه

- [x] منابع نور اصلی/پرکننده و نورهای موضعی مانیتور/آرکید را در نماهای overview و focus تنظیم کن.
- [x] roughness، metalness، رنگ و emissive را بر اساس جنس واقعی سطح‌ها تنظیم کن؛ لبه‌های مدل و سایهٔ تماس باید در کادر قابل‌خواندن باشند.
- [x] سایه و tone mapping را با assetهای واقعی تنظیم کن؛ post-processing یا dependency تازه فقط با نیاز اندازه‌گیری‌شده اضافه شود.
- [x] screenshotهای overview، focus مانیتور، برد و آرکید را در viewportهای هدف ثبت و مقایسهٔ بصری کن.

## گزارش اجرا — ۲۰۲۶-۱۰-۲۱

- شدت نور محیطی از `0.5` به `0.8` و نور جهت‌دار از `1.15` به `1.6` رسید؛ نور گرم میز کمی کاهش یافت و نورهای موضعی فعلی برای قاب مانیتور و لبهٔ آرکید بازتنظیم شدند. سایهٔ `percentage` حفظ شد: در Three.js نصب‌شده، `soft` هشدار می‌داد و به PCF برمی‌گشت؛ PCF فعلی خودش فیلتر نرم دارد. بازتاب تند صفحهٔ آرکید در مقایسهٔ تصویری به نور جانبی تبدیل شد.
- casing مانیتور در `scripts/build-room-furnishings.mjs` از مشکی فلزی به charcoal روشن‌تر و مات‌تر تنظیم و GLB بازتولید شد. ابعاد و هندسه ثابت ماندند: `12.708 × 3.865 × 2.750 m` و `236808` بایت. بازتولید دوباره همان هش `bb1ae48651a2e60b06e3f6a4c24a3604413ab47e113b78f100e0fc59242d0fe7` را داد.
- tone mapping پیش‌فرض R3F، یعنی ACES Filmic با exposure برابر ۱، حفظ شد؛ مقایسهٔ خروجی نورهای تأکیدی را کنترل‌شده نشان داد و نیازی به تغییر exposure یا افزودن post-processing نبود. هیچ وابستگی تازه‌ای اضافه نشد.
- screenshotهای overview و focus مانیتور، برد و آرکید در عرض‌های ۷۶۸، ۱۰۲۴ و ۱۴۴۰ با مرورگر محلی ثبت و بازبینی شدند (`.playwright-mcp/r04-*.png`). console خطا نداشت؛ هشدار deprecation موجود `THREE.Clock` باقی است. بررسی GPU فیزیکی انجام نشد.
- `node scripts/build-room-furnishings.mjs`: موفق؛ assertionهای ساختار GLB و bounds پاس شدند. `npm test`: ۱۴ تست موفق. `npm run lint`، `npm run typecheck`، `npm run build`، `npm run test:e2e -- --workers=1` (۲۵ تست Chromium) و `npm audit --audit-level=high` (صفر آسیب‌پذیری) موفق؛ `git diff --check` نیز موفق.
- در `HEAD` و `origin/main` workflow گیت‌هاب وجود ندارد؛ اجرای GitHub Actions ممکن نبود. R09 همچنان مسئول اندازه‌گیری عملکرد کلی است. مستندات محلی R04 و index فعال به‌روز شدند؛ PRD نیازی به تغییر نداشت. commit و push انجام نشد.
