# R14 — هندسه و پرداخت کنترل‌شدهٔ میز تأییدشده

**وضعیت:** در ۲۰۲۶-۱۰-۲۲ پیاده‌سازی و بررسی فنی تکمیل شد؛ قاب R13 ثابت ماند. **وابستگی:** R13 با تأیید صریح انسانی. **خروجی:** سطح و پیشانی نهایی میز در GLB محلی، بدون افزودن وسایل.

## هدف و تصمیم‌های الزام‌آور

ابعاد و قاب تأییدشدهٔ R13 مبناست؛ این کارت عمق را از نو طراحی نمی‌کند. میز باید یک صفحهٔ افقی پیوسته با ضخامت و لبهٔ جلویی خوانا باشد، پایهٔ مانیتور را درست حمل کند و به‌جای «نوار نارنجی» به‌صورت سطح کار دیده شود. از هندسه و متریال تولیدشده توسط `scripts/build-room-furnishings.mjs` استفاده کن؛ بازتولید GLB بخشی از تغییر است. BFCM فقط مرجع حس دیدِ سطح میز است و مدل، طرح، رنگ و وسایل آن کپی نمی‌شوند.

## فایل‌ها و اثرهای جانبی که باید بررسی شوند

- `scripts/build-room-furnishings.mjs` و `public/assets/models/room-furnishings.glb`: شکل، نام‌ها، bounds و خروجی دودویی.
- `src/RoomScene.tsx`: بارگیری GLB، نور/سایه و جای عناصر؛ `src/monitorAsset.test.ts`: قرارداد مدل؛ `src/roomCamera.ts` فقط اگر تغییر ضروریِ مصوب R13 در bounding دیده شد.
- `tests/room-navigation.spec.ts`, `tests/monitor.spec.ts` و `src/monitorProjection.test.ts`: نما، انتقال و تصویر مانیتور. مدل curved مانیتور و اسکریپت آماده‌سازی آن نباید بی‌دلیل دستکاری شوند.

## نتیجهٔ پیاده‌سازی و شواهد

- `DeskTop`: ابعاد و pose R13 حفظ شدند: `11.6 × 0.18 × 4.6`, مرکز `(0, 1.8, 1.4)`, محدودهٔ `z=-0.9..3.7`, سطح بالا `y≈1.89`. رنگ سطح `#513a2c`, roughness `0.76` است.
- `DeskFrontEdge`: عرض `11.48`, ارتفاع `0.18`, عمق `0.1`, مرکز `(0, 1.8, 3.75)`؛ متریال لبهٔ موجود `#51321d`. لبهٔ جلویی صفحه همچنان در `z=3.7` تمام می‌شود و پیشانی تا `z=3.8` امتداد دارد.
- مولد: `node scripts/build-room-furnishings.mjs`؛ GLB برابر `12.708 × 3.820 × 5.220 m`, `142236` بایت. SHA-256 در دو اجرای پیاپی `633adcabe28dce3a093fdf5a373ba3b33a8dc072f920a25179492177d5e1ad99` بود.
- بررسی‌ها: `npm test` → ۱۳ فایل و ۵۶ تست؛ `npm run lint`, `npm run typecheck`, `npm run build`, `git diff --check` پاس. E2E: `npx playwright test tests/room-navigation.spec.ts tests/monitor.spec.ts --workers=1` → ۳۳ پاس.
